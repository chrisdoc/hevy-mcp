## Summary

The `create-routine` MCP tool appears to expose a schema that does not match what the runtime accepts.

Read-only Hevy MCP operations work correctly, including:

- `get-training-summary`
- `search-exercise-templates`
- routine/exercise discovery

However, when attempting to create a routine using the documented `create-routine` schema, the write invocation is rejected before the routine is created.

This suggests a mismatch between:

1. the MCP schema exposed to the client, and
2. the payload shape or wrapper expected by the runtime/handler.

## What I was trying to do

Create a new 3-day full-body routine in Hevy based on an existing workout analysis.

The routine was designed for:

- 3 sessions/week
- ~45–55 minutes/session
- 2 working sets per exercise
- mostly 1–3 RIR
- controlled ROM
- low-back friendly exercise selection
- hypermobility-aware execution
- ADHD-friendly "minimum viable workout" structure where the first 4 exercises are the essential portion
