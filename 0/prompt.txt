## Issue description
`preloadHevyToolSchemas()` populates the configuration cache but does not invoke the lazy Standard Schema JSON converters. Force the same input/output conversions consumed by `registerTool` during preload so first-request server registration only reads already-converted schemas.

## Issue Context
`compactJsonSchema()` stores `z.toJSONSchema()` behind memoized `jsonSchema.input` and `jsonSchema.output` closures. Add a regression test that verifies preload performs conversion before any server is built and that repeated preload/server construction does not repeat it.
